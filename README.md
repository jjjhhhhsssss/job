# 마감임박 채용 모아보기

여러 채용 사이트에 흩어진 공고를 **마감일 순으로 한 화면에** 모아 보여주는 취업준비생용 정적 웹사이트입니다.

- 접속일(한국시간) 기준 **마감 7일 이내** 공고를 마감이 가까운 순으로 20개씩 보여줍니다.
- 대상 분야: 연구·R&D, 품질관리(QA·QC), 생산·제조, 바이오·제약, 화학·소재, 식품, 환경·안전, 농업·축산, 사무·관리
- IT·전기·전자·기계·컴퓨터 전공 지식이 필요한 공고는 제외합니다.
- 상단에서 **모집분야 / 지역(시·도) / 검색어**로 거를 수 있습니다.

## 표 항목

| 항목 | 내용 |
| --- | --- |
| 회사명 | 회사명 + 공고 제목 |
| 모집분야 | 위 대상 분야 중 해당하는 것 |
| 담당업무 / 자격요건 / 우대사항 | 공고 본문에서 자동 추출 (자격요건 아래 `필수 조건` 별도 표시) |
| 채용 형태 | 정규직·계약직 등 (계약 기간이 있으면 함께 표시), 아래에 수습 기간 |
| 근무지 / 연봉 | 공고에 적힌 값 |
| 마감일 및 시간 | D-day 표시 |
| 지원 사이트 | 원문 공고로 바로 가는 링크 (같은 공고가 여러 사이트에 있으면 모두 표시) |

본문이 이미지로만 된 공고는 항목을 뽑을 수 없어 `공고 원문 참조`로 표시합니다.

## 수집 방식

- `scripts/collect.mjs` (Node.js 20, 외부 라이브러리 없음)가 각 사이트를 읽어 `data/jobs.json`을 만듭니다.
- GitHub Actions(`.github/workflows/collect.yml`)가 **매일 한국시간 0시 5분**에 실행해 데이터를 갱신합니다. 같은 날에는 몇 번 접속해도 그날 수집한 데이터를 씁니다.
- 어떤 사이트 수집이 실패하면, 그 사이트의 이전 공고 중 아직 마감 전인 것을 유지합니다.

| 사이트 | 방식 |
| --- | --- |
| 잡다 | 공개 API (목록 + 상세) |
| 자소설닷컴 | 채용 달력 API (상세는 이미지 위주라 링크만) |
| 사람인 | 검색 결과(마감임박순) + 상세 본문 |
| 잡코리아 | 검색 결과(마감임박순) + 상세 요강 |
| 고용24 | 검색 결과(마감일순) + 상세 |
| 잡알리오 | 공공기관 채용 목록(NCS 분야별) + 상세 |

링크드인은 공고에 마감일이 없고, 잡플래닛은 자동 접근을 막고 있어(403) 제외했습니다.

## 로컬 실행

```bash
node scripts/collect.mjs     # data/jobs.json 생성
npx serve .                  # 또는 아무 정적 서버로 index.html 열기
```

## 폴더 구조

```
index.html, style.css, app.js   화면
data/jobs.json                  수집 결과
scripts/collect.mjs             수집 실행
scripts/lib/sources.mjs         사이트별 수집기
scripts/lib/util.mjs            HTML→텍스트, 항목 추출, 분야·지역 분류
.github/workflows/collect.yml   매일 자동 수집
```
